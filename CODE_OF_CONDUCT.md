# Code Of Conduct

GroundTrace should be a practical, respectful place to collaborate. This code of conduct applies to project spaces such as issues, discussions, pull requests, and community channels.

## Expected Behavior

- Be direct without being hostile.
- Assume others are working with incomplete context.
- Keep technical disagreement focused on evidence, tradeoffs, and user impact.
- Credit ideas in discussion without turning public docs into personal attribution pages.
- Respect privacy when traces, logs, prompts, or customer data are involved.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Sharing sensitive trace data that does not belong in public.
- Repeatedly derailing technical discussion after maintainers ask to refocus.
- Misrepresenting project affiliation or decision authority.

## Enforcement

Maintainers may edit or remove comments, close threads, block accounts, or restrict participation when behavior harms the project. Reports should be sent privately through the repository's normal maintainer or security contact path.

Maintainers should handle reports with discretion, avoid unnecessary disclosure, and explain moderation decisions when doing so would not expose private information.
